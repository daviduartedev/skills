# Narrative

Print these headings in this order. Keep each section to what the sources support.

## What it is

One short block: the module's job in the product, who it is for, and what it is not (only when a source states the exclusion).

## How it connects

Neighbouring modules and shared language (glossary terms). A missing join is one explicit **open** line.

## Decided

Bullet rules the sources already close. Each bullet ends with a source path or issue number.

## Open

Bullet questions the sources leave unset. Include wording still provisional, scoring rules still missing, and screens still unbuilt when the spec names them as open.

## Out of scope

What this slice refuses, when a source says so.

## Sources read

Paths and issue numbers actually opened in this run.
