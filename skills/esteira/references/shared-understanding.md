# Shared understanding

Load when the scope and the branch exist and the spec is not published yet.

Interview in rounds. A round asks only questions that can be answered without another question in that same round still open. Number each question and give one recommended answer. Ground the recommendation in the consumer repo (code, docs, ADRs). Wait for the user's answers before the next round.

Look up facts in the repo. Leave decisions to the user.

When a term is settled and the consumer has `CONTEXT.md`, add the term there when it is missing. When a decision constrains later work and the consumer keeps ADRs, write one ADR for that decision.

The user confirms the shared understanding in this conversation. The spec is published in a later step.
